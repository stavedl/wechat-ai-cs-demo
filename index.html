二、项目背景与目标

企业通过微信群触达和服务客户，但人工客服存在响应不及时、夜间无人值守、答复口径不统一、潜在商机流失等问题。本方案搭建一套通用型微信群智能AI客服系统，不区分客户类型，统一服务标准，覆盖售前、售中、售后全流程。

  • 7×24 小时秒级响应，首次响应 ≤ 5 秒；
  • 基于知识库与服务案例库精准解答，自助解决率 ≥ 70%；
  • 自动识别高意向客户并实时推送销售团队；
  • AI 无法处理时平滑转人工，全程留痕、可统计。

三、功能需求

3.1 售前场景

编号功能需求描述
S17×24 咨询应答全天候响应产品/服务咨询：功能、价格、版本对比、合作流程等。

3.2 售中场景（示例业务：在线课程购买）

编号功能需求描述
M1下单引导客户表达购买意向后，AI 按需求匹配班型/套餐（基础/进阶），多轮澄清后生成下单链接或订单。
M2优惠核销自动识别客户可用优惠（群专属券、限时折扣、老学员价），下单时直接核算到手价。
M3催付挽单订单创建后未支付（如 30 分钟）自动提醒，结合优惠到期、名额紧张话术挽单；识别犹豫原因并答疑或转课程顾问。
M4支付确认与回执支付成功自动回执订单信息、开班时间、后续安排（拉班级群、预习资料、开发票入口）。
M5履约提醒开班前 N 天自动提醒、推送预习资料；实物类业务对应发货/物流通知。
M6改单/退款受理换班、改期、退款申请自助受理，按规则自动处理或转人工审核。
M7成交同步成交后自动推送运营/销售（含转化路径），分配班主任/客户成功，进入服务交接流程。

五、系统架构

整体链路：微信群消息 → 接入层（企业微信机器人/群托管账号）→ 消息网关（去重、限流、触发规则）→ 意图识别引擎 → ① RAG 检索 + 大模型生成 → 合规审核 → 回复入群；② 高意向 → 线索引擎 → 推送销售（企微/CRM）；③ 复杂问题 → 人工坐席工作台
层级组成说明
接入层企业微信群机器人 / 微信群托管推荐企业微信官方方案；个人微信托管存在封号风险需评估
对话引擎LLM + 意图识别 + 多轮对话管理上下文记忆、追问澄清、人设话术配置
知识层RAG 知识库 + 案例库 + FAQ向量+关键词混合检索，答案带来源，防幻觉
业务集成CRM / 工单 / 订单 / 物流接口线索与工单双向同步
人工协同客服工作台会话接管、上下文摘要、AI 辅助答复建议
管理后台知识库、规则、看板、权限管理员自助维护
